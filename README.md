
# 🕷️ Spider Web Network

Telegram Mini App game project.

## Features

- 🏠 Home Dashboard
- 🎮 Spider Tic-Tac-Toe
- 🎯 Tasks & Missions
- 👥 Referral System
- 🏆 Global Leaderboard
- 👤 User Profile
- 💎 NFT Collection
- 🛠️ Admin Panel
- 📱 Telegram Mini App Support
- 🌐 Mobile Friendly

## Project Structure

│
├── admin/

│

## Referral System

Fixed referral rewards.

No referral commission system.

## Withdraw

Withdrawal is currently disabled.

Withdraw can be enabled later after the backend and security system are ready.

## Admin Panel

Admin panel will manage:

- Users
- Tasks
- Rewards
- Referrals
- Games
- NFT Collections
- Leaderboard
- Notifications
- Settings

## Backend

MySQL database structure is included in:

backend/schema.sql

Future backend will handle:

- Telegram authentication
- User accounts
- Tasks
- Rewards
- Referrals
- XP
- Leaderboard
- NFT data
- Admin controls

## Development Status

This is currently a frontend/demo foundation.

Real rewards, database operations, authentication, anti-abuse protection and withdrawal functionality will be added during backend development.

## Mobile Development

The project can be developed and managed from a mobile phone using GitHub and a mobile code editor.
